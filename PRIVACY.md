# Privacy Policy

Last updated: May 5, 2026

Ceylantify YouTube is a Chrome extension that adds bundled Ceylan PNG overlays to YouTube thumbnail images in the user's browser.

## Data Collection

Ceylantify YouTube does not collect, store, sell, share, or transmit any user data.

The extension does not collect:

- Personally identifiable information
- Health information
- Financial or payment information
- Authentication information
- Personal communications
- Location information
- Web history
- User activity
- Website content

## Website Access

The extension runs only on YouTube pages:

- `https://www.youtube.com/*`
- `https://m.youtube.com/*`

This access is used only to find YouTube thumbnail elements and place local bundled PNG overlays on top of them. All processing happens locally in the browser.

## Remote Code

Ceylantify YouTube does not use remote code. All JavaScript, CSS, and image assets are included in the extension package.

For questions or issues, please use the GitHub repository issue tracker.
