# Privacy Policy for Louistify YouTube

Last updated: May 10, 2026

Louistify YouTube is a browser extension that adds bundled transparent Louis image overlays to YouTube thumbnail images in the user's browser.

## Data Collection

Louistify YouTube does not collect, store, sell, share, or transmit any user data.

The extension does not collect:

- Personally identifiable information
- Health information
- Financial or payment information
- Authentication information
- Personal communications
- Location information
- Web history
- User activity
- Website content

## Website Access

The extension runs only on YouTube pages:

- `https://www.youtube.com/*`
- `https://m.youtube.com/*`

This access is used only to find YouTube thumbnail elements and place local bundled PNG overlays on top of them. All processing happens locally in the browser.

## Remote Code

Louistify YouTube does not use remote code. All JavaScript, CSS, icons, and image assets are included in the extension package.

## Data Sharing

Louistify YouTube does not share user data with third parties because it does not collect user data.

## Contact

For questions or issues, please use the GitHub repository issue tracker.
